1) Создай репозиторий на github.com (New repository).
2) Загрузи СОДЕРЖИМОЕ этой папки (Add file > Upload files), включая папку .github.
   Если .github не видна — включи показ скрытых файлов или загрузи через "Create new file" с путём .github/workflows/build.yml.
3) Вкладка Actions > build > дождись зелёной галочки (2-5 мин).
4) Внизу страницы запуска, раздел Artifacts > xbow-cart-jar — скачай, распакуй, получишь xbow-cart-1.0.0.jar.
5) Положи jar в .minecraft/mods вместе с Fabric Loader 0.18+ и Fabric API для 1.21.11.
